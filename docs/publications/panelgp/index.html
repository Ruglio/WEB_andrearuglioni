PanelGP: A Probabilistic Factor Model for Asset-Return Panels

Working paper

Abstract

We develop PanelGP, a conditional factor model for large panels of stock returns in which firm characteristics determine the factor loadings and economic conditions determine the expected factors. Both relations are estimated nonparametrically with Gaussian-process priors. The kernel choice nests instrumented principal component analysis (IPCA) as well as smooth nonlinear maps. Asset-specific loading innovations and common factor innovations separate idiosyncratic from systematic risk, so one estimated model forecasts both expected returns and their covariance matrix. Estimation uses sparse variational inference with a joint posterior over loadings and factors. Because each predicted return is bilinear in a Gaussian state, the predictive covariance matrix and the cumulants of any portfolio have closed forms. In simulations, the estimator recovers the nonlinear maps and the variance parameters. For S&P 500 constituents over 1995–2024, nonlinear loadings rank stocks better than affine loadings and improve the Gaussian log score. Relative to IPCA, the resulting portfolios have higher Sharpe ratios, also net of trading costs, and the minimum-variance portfolio has lower volatility. The predicted variances rank stocks and months by risk but are too compressed.

In brief

The model

Asset i at date t has characteristics x_{it} \in \mathbb{R}^P, and all assets share an economic context c_t \in \mathbb{R}^Q. A loading map \beta sends characteristics to H factor loadings, and a factor map \phi sends the context to the expected factors of the next period. Realized loadings and factors deviate from these maps by Gaussian innovations,

\begin{aligned} \tilde\beta_{it} &= \beta(x_{it}) + \xi_{i,t+1}, & \xi_{i,t+1} &\sim \mathcal{N}(0, D_\beta), \\ \tilde\phi_{t} &= \phi(c_{t}) + \zeta_{t+1}, & \zeta_{t+1} &\sim \mathcal{N}(0, D_\phi), \end{aligned}

and the excess return is bilinear in the two:

r_{i,t+1} = \tilde\beta_{it}^\top \tilde\phi_t + \sigma_r\,\epsilon_{i,t+1}, \qquad \epsilon_{i,t+1} \sim \mathcal{N}(0, 1).

Each component of the two maps gets an independent Gaussian-process prior, \beta_h \sim \mathcal{GP}(0, k_{\beta,h}) and \phi_h \sim \mathcal{GP}(0, k_{\phi,h}). Affine loading kernels with constant factor kernels give the structure of IPCA; RBF kernels allow nonlinear loadings and factor forecasts that depend on the context.

The loading innovation is specific to each asset, while the factor innovation is common to all assets at a date, which separates idiosyncratic from systematic risk. The model is estimated by sparse variational inference.

The predictive distribution

For a new panel of J returns, stack its realized loadings and factors into a latent state \chi_\star. Its predictive distribution is Gaussian, \chi_\star \sim \mathcal{N}(m_\star, \tilde S_\star), and each new return is a quadratic form in this state,

r_{\star j} = \chi_\star^\top A_j\, \chi_\star + \sigma_r\,\epsilon_{\star j},

where A_j pairs the loadings of row j with the factors of its date. Writing A(s) = \sum_{j} s_j A_j, the joint cumulant generating function of the new panel, K(s) = \log \mathbb{E} \exp(s^\top r_\star), is available in closed form:

K(s) = -\tfrac{1}{2} \log \bigl| I - 2 \tilde S_\star A(s) \bigr| + m_\star^\top A(s) \bigl( I - 2 \tilde S_\star A(s) \bigr)^{-1} m_\star + \tfrac{1}{2} \sigma_r^2\, s^\top s,

finite whenever \tilde S_\star^{-1} - 2A(s) is positive definite. Its derivatives at zero give the predictive mean, the covariance matrix and the higher cumulants of any portfolio w^\top r_\star. The predictive distribution can therefore be skewed and have excess kurtosis, while its tails decay at least exponentially.

Results

The models are estimated on 1960–1989 and evaluated out of sample on S&P 500 constituents from 1995 to 2024.

Plot = import("https://cdn.jsdelivr.net/npm/@observablehq/plot@0.6.16/+esm")

results = FileAttachment("results-by-factors.csv").csv({ typed: true })

series = [
  "PanelGP, RBF loadings and factors",
  "PanelGP, affine loadings (IPCA-like)",
  "IPCA with intercept"
]

fmt = (metric, v) => metric.startsWith("Rank") ? `${v.toFixed(2)}%` : v.toFixed(2)

function panel(metric, panelWidth) {
  const rows = results.filter(d => d.metric === metric);
  const marks = [Plot.gridY({ stroke: "currentColor", strokeOpacity: 0.12 })];
  if (metric.startsWith("Tangency")) {
    marks.push(
      Plot.ruleY([0.62], { className: "pg-ref", strokeWidth: 1 }),
      Plot.text([{ x: 8, y: 0.62 }], { x: "x", y: "y", text: () => "S&P 500", dy: -7, textAnchor: "end", className: "pg-ref-label" })
    );
  }
  series.forEach((s, i) => {
    const d = rows.filter(r => r.model === s);
    if (d[0].seeds > 1) marks.push(Plot.areaY(d, { x: "factors", y1: "low", y2: "high", curve: "linear", className: `pg-band-s${i}` }));
  });
  [...series].reverse().forEach((s) => {
    const i = series.indexOf(s);
    const d = rows.filter(r => r.model === s);
    marks.push(
      Plot.lineY(d, { x: "factors", y: "mean", strokeWidth: 2, className: `pg-line-s${i}` }),
      Plot.dot(d, { x: "factors", y: "mean", r: 3.5, className: `pg-dot-s${i}` })
    );
  });
  marks.push(Plot.tip(rows, Plot.pointer({
    x: "factors", y: "mean",
    title: d => `${d.model}\nH = ${d.factors}: ${fmt(metric, d.mean)}` +
      (d.seeds > 1 ? `\nacross seeds: ${fmt(metric, d.low)} to ${fmt(metric, d.high)}` : "")
  })));
  return Plot.plot({
    width: panelWidth, height: 280,
    marginLeft: 44, marginRight: 12, marginTop: 28, marginBottom: 40,
    style: { background: "transparent", color: "currentColor", fontFamily: "Inter, sans-serif", fontSize: "12px" },
    x: { label: "Number of factors H", ticks: [1, 2, 3, 4, 5, 6, 7, 8], tickFormat: "d", labelAnchor: "center", labelOffset: 34 },
    y: { label: metric, labelAnchor: "top", labelArrow: "none", nice: true },
    marks
  });
}
chart = {
  // Drawn at a fixed size and scaled by CSS to fill each grid column.
  const panelWidth = 420;
  const legend = html`<div class="pg-legend">${series.map((s, i) =>
    html`<span class="pg-key"><span class="pg-swatch pg-s${i}"></span>${s}</span>`)}</div>`;
  const rows = series.flatMap(s => [1, 2, 3, 4, 5, 6, 7, 8].map(h => {
    const get = m => results.find(d => d.model === s && d.factors === h && d.metric === m).mean;
    return html`<tr><td>${s}</td><td>${h}</td><td>${get("Rank correlation (%)").toFixed(2)}</td><td>${get("Tangency Sharpe ratio").toFixed(2)}</td></tr>`;
  }));
  return html`<figure class="pg-chart">
    ${legend}
    <div class="pg-panels">
      ${panel("Rank correlation (%)", panelWidth)}
      ${panel("Tangency Sharpe ratio", panelWidth)}
    </div>
    <figcaption>Out-of-sample results by number of factors, 1995–2024, with models estimated on 1960–1989 and held fixed. PanelGP lines average five optimization seeds and the bands span them; the paper uses H = 5. Data from the <a href="https://github.com/Ruglio/PanelGP" target="_blank" rel="noopener">replication package</a>.</figcaption>
    <details class="pg-table"><summary>Show the data</summary>
      <table><thead><tr><th>Model</th><th>H</th><th>Rank correlation (%)</th><th>Tangency Sharpe ratio</th></tr></thead>
      <tbody>${rows}</tbody></table>
    </details>
  </figure>`;
}
